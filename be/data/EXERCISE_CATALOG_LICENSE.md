# Exercise catalog data license

The file `exercise-catalog.json` is derived from
[yuhonas/free-exercise-db](https://github.com/yuhonas/free-exercise-db)
(`dist/exercises.json`).

That dataset is released as **public domain / open data** for reuse.
Image URLs in the JSON point at the upstream GitHub `raw` CDN:

`https://raw.githubusercontent.com/yuhonas/free-exercise-db/main/exercises/...`

We keep a **slim** subset of fields for search (no full instruction text)
to keep the repo payload small.

Upstream: https://github.com/yuhonas/free-exercise-db
